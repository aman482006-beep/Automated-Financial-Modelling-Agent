# Support

ModelForge is an independently maintained, browser-first financial-modelling project. Support is provided on a best-effort basis.

## Where to ask

- **Bug reports:** use the Bug report issue form. Include steps to reproduce, expected and actual results, browser and a synthetic example.
- **Feature ideas:** use the Feature request issue form. Explain the workflow problem before proposing a solution.
- **Security vulnerabilities:** follow the private reporting instructions in [SECURITY.md](SECURITY.md). Do not open a public issue with exploit details.
- **Usage questions:** first check the README, [formula reference](docs/formulas.md) and [data / privacy guide](docs/data-sources-and-privacy.md). If the question remains, open an issue with a minimal synthetic example.

## Please do not share

Never attach real client workbooks, personal financial information, credentials, account identifiers, passwords, API keys or material non-public information. Replace company data with fictional values before sharing a reproduction.

## Scope

ModelForge is educational and analytical software, not investment advice, accounting software, a broker or a production financial-data service. It does not fetch or authenticate filings or market prices. Questions about a security's current value, suitability or expected return are outside the support scope.
