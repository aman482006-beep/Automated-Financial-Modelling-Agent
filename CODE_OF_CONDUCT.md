# Code of Conduct

## Our pledge

We want participation in ModelForge to be welcoming, respectful and focused on improving the software. Everyone who contributes, reports a problem or asks a question should be treated with patience and respect.

## Expected behaviour

- Be respectful and constructive; critique code and ideas, not people.
- Explain disagreements with evidence and clear reasoning.
- Welcome people with different experience levels and backgrounds.
- Assume good intent while taking the impact of behaviour seriously.
- Keep discussions focused on the project and its users.
- Protect privacy: never publish credentials, personal data, private financial information or material non-public information.

## Unacceptable behaviour

Harassment, discrimination, insults, threats, doxxing, deliberate intimidation, sexualised conduct, spam and repeated disruptive behaviour are not acceptable.

## Maintainer response

The maintainer may edit or remove content, close discussions, or restrict participation when behaviour violates this policy. Reports should be made privately through the maintainer's GitHub profile. For security vulnerabilities, use the process in [SECURITY.md](SECURITY.md).

This code of conduct applies to project spaces, including issues, pull requests and discussions.
